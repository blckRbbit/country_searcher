# ПОИСК СТРАНЫ

## Описание

Приложение определяет название страны по номеру телефона.

## Запуск приложения

1. Убедитесь что у вас установлены JDK 11 и выше и Gradle 7.5 и выше;
2. Склонируйте репозиторий:
    ```bash
   git clone https://github.com/blckRbbit/country_searcher.git
   ```
3. Перейдите в корневую папку проекта:
    ```bash
   cd country_searcher
   ```
4. !!! Вы можете запустить приложения из любой среды разработки, настроенной для java;

## Консольные команды
### (выполняются из корня проекта)

1. Для Windows команды необходимо выполнять в unix-подобных консольных утилитах: WCL, git-bash и.т.п;
1. В UNIX-подобных системах выдайте права на выполнение файлов:
    ```bash
   chmod +x build.sh
   chmod +x test.sh
   chmod +x run.sh
   ```
    для Windows этого делать не нужно
2. Убедитесь, что порт 8088 в вашей системе свободен.
3. Команда ```./run.sh``` произведет полный цикл развертывания приложения, включая тесты, формирование отчетов по ним, сборку 
приложения и его запуск;
4. Команда ```./test.sh``` запустит тесты и сформирует отчет по ним
5. Команда ```./build.sh``` запустит сборку проекта
6. После запуска, интерфейс приложения будет доступен в браузере, по адресу localhost:8088.
